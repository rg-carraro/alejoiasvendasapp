# Checklist de regressão

Após mudanças, testar pelo menos:

- [ ] app abre sem crash;
- [ ] base SQLite existente abre sem perda;
- [ ] clientes aparecem;
- [ ] nova venda simples;
- [ ] nova venda parcelada;
- [ ] edição de venda;
- [ ] exclusão;
- [ ] pagamento parcial;
- [ ] segundo pagamento;
- [ ] data de pagamento;
- [ ] correção de valor pago;
- [ ] cobrança WhatsApp;
- [ ] filtros;
- [ ] pesquisa;
- [ ] resumo financeiro;
- [ ] resumo mensal;
- [ ] resumo por cliente;
- [ ] dashboard;
- [ ] PDF;
- [ ] CSV;
- [ ] backup;
- [ ] Planilha → SQLite;
- [ ] SQLite → Planilha;
- [ ] sync repetido sem duplicação;
- [ ] funcionamento offline.
