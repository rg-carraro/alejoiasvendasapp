# Funcionalidades existentes

A versão estável possui, entre outras, as seguintes capacidades que devem ser preservadas:

## Vendas
- nova venda;
- cliente;
- descrição;
- valor;
- data;
- parcelas;
- vencimentos;
- edição;
- exclusão.

## Lista/cards
- exibição de valores;
- valor pago;
- saldo;
- vencimento;
- estados visuais;
- filtros;
- pesquisa;
- cobrança via WhatsApp.

## Pagamentos
- pagamento parcial;
- data de pagamento;
- correção de valor;
- vínculo pelo `id_venda`.

## Relatórios
- resumo financeiro;
- resumo por período;
- resumo mensal;
- resumo por cliente;
- dashboard;
- histórico de cliente;
- busca global.

## Saídas
- PDFs;
- CSV;
- compartilhamento;
- backup local.

## Integração
- importação da planilha para SQLite;
- envio SQLite para planilha;
- sincronização;
- Apps Script.

## Notificações
- alertas relacionados a vencimentos.

Esta lista é uma referência de compatibilidade. Antes de remover ou modificar qualquer item, verificar a implementação real no código.
