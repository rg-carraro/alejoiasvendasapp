# Marco AleJoias — 24/09/2026

Tag: `alejoias-v2-marco-2026-09-24`. Branch de manutenção: `master`.

Este marco preserva o AleJoias SQLite Sync v2 com o layout simples, botões
espaçados, acesso a todas as fotos, PDF financeiro coerente com o mês do painel,
cobrança WhatsApp com parcelas e pagamentos, menu no cabeçalho e área segura
para câmera e barras do sistema. Vendas, fotos, pagamentos, relatórios, CSV,
backup e integração Google Planilhas permanecem disponíveis.

O usuário aprovou a evolução. A última compilação `assembleDebug` passou;
o checklist detalhado no telefone continua sendo a referência para regressão.
Isso não representa homologação completa de todos os cenários do checklist.

## Linha comercial independente

A branch `comercial` parte deste marco para criar **Vendas Simples**, em azul
e cinza, sem identidade de joalheria e sem backend de planilha. Mantém as
operações locais e o formato de navegação. Não integrar essa remoção de sync
na `master`. O aplicativo comercial terá identificador próprio para poder
coexistir com AleJoias no mesmo aparelho e manter os dados separados.

Publicar mudanças comerciais apenas em `comercial`; mudanças AleJoias em
`master`. A tag é um ponto de recuperação e não deve ser movida.
