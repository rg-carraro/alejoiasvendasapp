# Contexto do projeto AleJoias Vendas para Codex

Este pacote transfere para o repositório o contexto técnico essencial acumulado durante o desenvolvimento do aplicativo.

## Como usar

1. Extraia este ZIP.
2. Copie `AGENTS.md` para a **raiz do projeto AleJoias Vendas SQLite Sync v2**.
3. Copie a pasta `docs/` para a raiz do projeto.
4. Abra a pasta completa do projeto no Codex.
5. Peça ao Codex para ler `AGENTS.md` e `docs/` antes de realizar a primeira alteração.

O código-fonte oficial continua sendo o pacote **AleJoias_Vendas_SQLite_Sync_v2** validado pelo usuário. Este ZIP é documentação/contexto, não substitui o código-fonte.

## Princípio

A versão SQLite Sync v2 é estável. Novas alterações devem ser pontuais e preservar tudo que já funciona.
