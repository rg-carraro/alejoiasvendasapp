# Contexto do projeto AleJoias Vendas para Codex

Esta pasta é o repositório atual e oficial do projeto **AleJoias Vendas SQLite Sync v2**, validado pelo usuário.

## Como usar

1. Abra no Codex a pasta completa deste projeto:
   `C:\Pessoal\AleJoias\projetos\aleajoiasvendas`.
2. Use esta própria pasta como diretório de trabalho; não é necessário copiar ou extrair outro pacote.
3. Antes de realizar alterações, leia `AGENTS.md` e a documentação da pasta `docs/`.
4. Considere o código presente neste repositório como a base oficial estável.

## Princípio

A versão SQLite Sync v2 é estável. Novas alterações devem ser pontuais e preservar todas as funcionalidades existentes, o banco SQLite, os IDs compartilhados e a sincronização com Google Planilhas.
